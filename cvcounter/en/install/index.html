Install CVCounter

Two paths: local Python setup or a single Docker Compose command.

View on GitHub

Python

git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
python3 -m venv venv
source venv/bin/activate   # Windows: .\\venv\\Scripts\\activate
pip install -r requirements.txt
cp config/config.example.json config/config.json
python app.py

Docker

git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
docker-compose up --build

After start, open the web UI on the port from config (8080 by default). Copy config.example.json → config.json and set the video source and model_type.
