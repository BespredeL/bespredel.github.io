Install CVCounter

1-click automatic install with GPU detection, manual Python setup, or Docker Compose.

View on GitHub

1-Click Automatic Installation (Recommended)

The installer automatically detects your hardware (NVIDIA CUDA, AMD DirectML, Intel Arc / OpenVINO, or CPU), configures a virtual environment, and installs dependencies:

Windows:

# Run 1-click installer:
install.bat

# Start the application:
start.bat

Linux / macOS:

chmod +x install.sh start.sh
./install.sh
./start.sh

Installer flags (install.py): --profile [nvidia_cuda|amd_directml|intel_openvino|cpu] to override hardware profile, --reinstall to force dependency reinstallation.

Manual Python Installation

git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
python3 -m venv venv
source venv/bin/activate   # Windows: .\venv\Scripts\activate
pip install -r requirements.txt

# Optional: for Ultralytics YOLO & .pt weights
pip install -r requirements-ultralytics.txt

# Optional: for Intel OpenVINO acceleration
pip install -r requirements-openvino.txt

cp config/config.example.json config/config.json
python app.py

Docker

git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
docker-compose up --build

After launch, navigate to http://localhost:8080 (configured in config.json). Initial config is created automatically on first run.

Supported Detection Backends

Auto

model_type: "auto"

Recommended: selects backend by model file extension

ONNX Runtime

model_type: "onnx"

.onnx · CUDA, DirectML, CPU

Intel OpenVINO

model_type: "openvino"

.xml/.bin, .onnx · Intel CPU, Arc, NPU

Ultralytics & TensorRT

model_type: "yolo"

.pt, .engine, .trt · CUDA / TensorRT

OpenCV DNN

model_type: "opencv"

.onnx, Darknet · Zero heavy dependencies
