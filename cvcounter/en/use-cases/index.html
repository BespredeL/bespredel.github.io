Frequently Asked Questions

Answers to common questions regarding scenario integration and hardware setups.

Can I run multiple use cases on a single CVCounter instance?

Yes. CVCounter lets you connect multiple camera feeds simultaneously. Each camera can have its own customized detection zones, target object classes (e.g., car/truck for gate cameras, person for door cameras), and independent counters.

How does CVCounter ensure counting accuracy across zones?

The platform incorporates ByteTrack multi-object tracking. Each object receives a persistent trajectory ID across video frames, incrementing counters only upon zone crossing and preventing duplicate counts for stationary or oscillating objects.

Is an internet connection required to run scenarios?

No. All CVCounter scenarios execute 100% on-premises (Air-Gapped) on your local hardware. Video feeds never leave your local network, ensuring absolute privacy and GDPR compliance.

Can I train models for proprietary, custom objects?

Yes. CVCounter features an integrated web dataset annotation tool: capture frames from live feeds, annotate bounding boxes in your browser, launch YOLO training with a single click, and deploy best.pt weights directly.
