Frequently asked questions

Answers on installation, inference backends, ByteTrack, and model training.

What is CVCounter?

An open-source computer vision system for real-time object detection, tracking (ByteTrack), and counting across RTSP, USB webcams, and video files, accessible via a responsive web UI.

How does object tracking work?

CVCounter utilizes ByteTrack: an advanced multi-object tracker that maintains consistent object IDs across frame boundaries even during temporary occlusions, eliminating duplicate counts.

Which detection backends are supported?

Supported backends include ONNX Runtime (CUDA, DirectML, CPU), Intel OpenVINO (.xml/.bin, .onnx), Ultralytics YOLO (.pt and TensorRT .engine), OpenCV DNN, and an auto mode that chooses the optimal engine based on model format.

How do I install CVCounter?

Recommended: 1-click automatic install via install.bat (Windows) or ./install.sh (Linux/macOS). The installer automatically detects NVIDIA CUDA, AMD DirectML, Intel OpenVINO, or CPU. Manual Python and Docker Compose setups are also available.

Can I train custom models?

Yes: an integrated dataset management module allows you to auto-collect stream frames, upload ZIP files, annotate boxes and polygons, run YOLO training in the web UI, and export weights to ONNX or TensorRT.

How do counting zones work?

Draw polygonal and rectangular zones in the interactive editor with vertex numbering, pan/zoom, and undo/redo history. Multiple independent counting zones can be configured per camera.

Does it support event recording and reports?

Yes: automatically records video clips and snapshots upon detection events, tracks batch and shift history, and produces printable A4 reports with signature blocks.

Can I display numbers without streaming video?

Yes: dedicated text and multi-text kiosk views show live counters with minimal CPU/GPU overhead, perfect for shop floor monitors and gate kiosks.

Does it require internet access?

No. Video capture, inference, and database operations run 100% locally on premise. Internet is only needed for initial dependency downloads or optional telemetry.

Which license applies?

AGPL-3.0. The full source code is freely available on GitHub.
