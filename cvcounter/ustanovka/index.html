Установка CVCounter

Автоматическая установка в 1 клик с автодетекцией GPU, ручная настройка Python или Docker.

Открыть на GitHub

Автоматическая установка в 1 клик (Рекомендуется)

Скрипт автоматически определит аппаратное обеспечение (NVIDIA CUDA, AMD DirectML, Intel Arc / OpenVINO или CPU), создаст виртуальное окружение и установит подходящие библиотеки:

Windows:

# Запустите установщик:
install.bat

# Запуск приложения:
start.bat

Linux / macOS:

chmod +x install.sh start.sh
./install.sh
./start.sh

Опции install.py: --profile [nvidia_cuda|amd_directml|intel_openvino|cpu] для явного профиля, --reinstall для переустановки.

Ручная установка (Python)

git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
python3 -m venv venv
source venv/bin/activate   # Windows: .\venv\Scripts\activate
pip install -r requirements.txt

# Опционально: для весов .pt и обучения YOLO
pip install -r requirements-ultralytics.txt

# Опционально: для аппаратного ускорения Intel OpenVINO
pip install -r requirements-openvino.txt

cp config/config.example.json config/config.json
python app.py

Docker

git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
docker-compose up --build

После запуска откройте веб-интерфейс в браузере: http://localhost:8080 (порт из config.json). При первом запуске конфигурация создаётся автоматически.

Поддерживаемые бэкенды детекции

Auto (Автовыбор)

model_type: "auto"

Рекомендуется: автоподбор движка по расширению файла модели

ONNX Runtime

model_type: "onnx"

.onnx · CUDA, DirectML, CPU

Intel OpenVINO

model_type: "openvino"

.xml/.bin, .onnx · Intel CPU, Arc, NPU

Ultralytics & TensorRT

model_type: "yolo"

.pt, .engine, .trt · CUDA / TensorRT

OpenCV DNN

model_type: "opencv"

.onnx, Darknet · Без тяжёлых зависимостей
