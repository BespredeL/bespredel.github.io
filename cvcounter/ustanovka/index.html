Установка CVCounter

Два пути: локально через Python или одной командой в Docker.

Открыть на GitHub

Python

                    
git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
python3 -m venv venv
source venv/bin/activate   # Windows: .\\venv\\Scripts\\activate
pip install -r requirements.txt
cp config/config.example.json config/config.json
python app.py

Docker

                    
git clone https://github.com/BespredeL/CVCounter.git
cd CVCounter
docker-compose up --build

После запуска откройте веб-интерфейс на порту из config (по умолчанию 8080). Скопируйте config.example.json → config.json и укажите источник видео и model_type.

Бэкенды детекции

Ultralytics YOLO

model_type: "yolo"

.pt · CUDA / CPU

OpenCV DNN

model_type: "opencv"

ONNX, Darknet, protobuf

ONNX Runtime

model_type: "onnx"

YOLO export → ONNX
